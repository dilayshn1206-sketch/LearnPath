# Unit discovery answer saving

Grammar choices now update one answer key through the existing atomic lp_write
merge, rather than reading and replacing every answer. Requests are serialized
within the tab. Choosing an answer updates its button immediately without
rebuilding the entire unit or downloading teacher images again.

An in-memory draft retains failed choices across unit reopening. A visible
Saving / Answers saved status and Retry saving action make persistence explicit.
Submission waits for queued saves and cannot complete with an unsaved choice.
Previously submitted records, assessment snapshots and answer keys are unchanged.

Verification: 38 regression checks including rapid choices across questions,
rapid changes to the same question, failure/retry, and final submitted snapshots.
The actual Supabase lp_write single-key merge was exercised as an enrolled
student inside a rolled-back transaction, preserving all live records.
