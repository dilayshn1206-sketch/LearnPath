# Prepared Compass workshop — 2026-11-02

Topic and product tiles show names/icons without explanatory subtext. The main
chooser offers Blog, Story/diary, Written interview; Podcast/audio, Short talk,
Role-play; Poster, Comic, Infographic, plus the existing own-product option.
How-to guide, spoken Interview and Visual slide story are not new choices. Their
metadata remains readable in existing plans. The bridge filters matching retired
IDs/names from teacher extras rather than silently reintroducing them. Other
teacher-defined choices and tools remain supported. No old student plans changed.

Compass uses `compass-library.js` for authored content and `compass-prepared.js`
for local intent/keyword routing and rendering. Replies contain a short heading,
2–5 keyword bullets and one guiding question. Coverage includes six digital-self
topics, nine active product formats, definitions, comparisons, alternative angles,
starting/structure, examples, audience/message development, research/credit,
language, tools/recording, combining formats, feedback, and speaking practice.
Goal-count guidance uses canonical passport goal text rather than separate numeric
targets. Context remembers the current topic/format and the last short follow-up;
alternate-angle requests rotate between prepared sets. It never selects a project
or completes an evaluation for the learner. Unknown inputs ask for clarification;
they are not treated as understood. Assessment-key requests receive learning hints.

The conversational route is finite prepared guidance, not an open-domain AI teacher.
There are no model, external chat, search or persistence calls. Four turns and a
draft/context remain in tab memory, with existing Back/Forward support. Rendered
user text and response fields are escaped. No access to learner records is added.

An “Ask me! Ask me!” bubble focuses the input. A transform on a wrapper gives the
original character a breakdance invitation before a conversation starts; the
transparent 24-frame, 3-second sprite itself is unchanged. Dancing pauses while
typing, with the existing motion control, in hidden tabs, and under reduced motion;
it stops once a reply is being read. No sound is forced.

Validation: 68 authored-response cases, real local form rendering with external
requests blocked, bullet DOM/escaping, draft Back/Forward, pause/reduced motion,
nine new formats, retired-format hiding and preserved saved Interview metadata.
The full planner/passport submission/edit flow also passes against mock records.
These scripted cases establish behavior, not coverage of every possible question
or an educational-effect claim. The previous live version is archived separately.
