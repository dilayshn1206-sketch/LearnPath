# LearnPath release, 28 October 2026

Replaces the existing Firebase frontend with the already configured Supabase
runtime, approved landscape atlas and transparent 24-frame/3-second companion.
No student records are deleted or migrated by this frontend release.

Includes supplied unit vocabulary/grammar, Words to learn after Word Check,
Google Sheets export status/key controls, the reviewed topic/product planner,
and Learning Passport. Passport now has Goals, Plan and Evaluation; focus and
project goals share one area. Evidence/detail, easy-to-understand and topic-
matters-to-me options are removed; the finish-step goal has no “at home”. The
structure goal has no extra explanation. The final mustard action saves and
sends to teacher approval, with a saved whole-passport summary afterwards.

Existing grouping, approval, unlock, evaluation, post/upload, shop, comment and
research paths remain. The authenticated host remains the sole persistence
owner. Prepared compass guidance is labelled; no AI provider is connected.

Validation: regression.cjs, browser.cjs, planner.cjs, supabase-adapter.cjs and
sheets-script.cjs. All browser tests use isolated fixture data and block external
requests. The production planner test covers save, grouped access, removed goals,
fixed I will prefix, scores, submit/lock, reopening, edits and tablet/mobile.
The live Google Sheets connector acknowledged event 44 at 15:34 UTC, confirming
scheduled sync after the earlier manually verified initial sync.
